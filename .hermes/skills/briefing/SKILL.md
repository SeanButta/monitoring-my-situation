# Daily Briefing Format — Midwest Workflow Co.

## Purpose
Produce a tight, specific, actionable daily intelligence briefing for Sean Fitzgerald.
No vague summaries. No filler. Every line must contain a real name, number, or specific finding.

## Rules for all briefing agents

- Always include real numbers — prices, percentages, headcounts, dollar amounts
- Always include real names — companies, people, products
- Never write "significant changes were observed" — say what changed
- Never exceed 25 lines total
- If nothing material changed in a section, write: "[Section]: No significant changes today"
- The ACTION / SO WHAT line is the most important — make it specific and executable
- Save output to the correct path before ending the session

---

## Output paths

| Report | Path |
|--------|------|
| World briefing | ~/reports/world/YYYY-MM-DD.md |
| Morning briefing | ~/reports/briefings/YYYY-MM-DD.md |
| Shared research | /shared-memory/RESEARCH.md |

---

## Quality bar

Before finishing, ask: "Could Sean read this in 60 seconds and know exactly what to do?"
If no — cut the filler and add specifics.
